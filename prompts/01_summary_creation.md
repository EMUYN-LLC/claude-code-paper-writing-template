# プロンプト 01 — 基本サマリー作成

以下のプロンプトをそのまま Claude Code に貼り付けて使います。
`{...}` の部分を実際の値に書き換えてから送信してください。

---

```
以下の論文の全文テキストを読み、`references/summaries/_template.md` のフォーマットで
基本サマリーを作成してください。

論文 PDF: references/pdfs/{PMID}.pdf

出力先: references/summaries/{著者姓}_{キーワード}_{PMID}.md

## 作成上の注意

- 数値はすべて論文テキストから正確に引用すること (推測・補完しない)
- 「論文執筆での引用ポイント」セクションには、このプロジェクトの各論文 (P01, P02 ...) で
  この文献をどう活用できるかを具体的に記載すること
- 二者協議セクションはまだ空欄のまま残す (後でエージェントが埋める)
- 作成後、`references/refs.yaml` に以下の形式でエントリを追加すること:
  tag: {著者姓}_{PMID}
```
