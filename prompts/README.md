# プロンプト集 — 使い方

## 事前準備: PDF の入手方法

エージェントに読ませるには論文の PDF が必要です。以下の合法的な方法で入手してください。

| 方法 | 説明 |
|---|---|
| **PubMed Central (PMC)** | NIH 助成論文の多くが無料公開。PMID から直接アクセス可能 |
| **Unpaywall** | ブラウザ拡張。論文ページを開くと OA 版を自動検出してくれる |
| **Open Access Button** | 著者最終稿 (accepted manuscript) を探してくれる |
| **ResearchGate** | 著者が自己アップロードしていることが多い |
| **著者への直接メール** | 合法かつ確実。「Could you share a reprint?」で返信率も高い |
| **機関図書館** | 所属施設の契約データベース (PubMed, Ovid, CiNii 等) を利用する |

入手した PDF は `references/pdfs/` に配置してください。

このフォルダには Claude Code へのコピペ用プロンプトが入っています。

## 手順

1. 対象論文の PDF が `references/pdfs/{PMID}.pdf` に配置されていることを確認する
2. `02_agent_statistician.md`、`03_agent_specialist.md` の
   2つのプロンプトを **同時に** Claude Code に貼り付けて送信する
3. 各プロンプト内の `{PMID}` と `{一時ディレクトリ}` を実際の値に置き換えてから送信する
4. 2エージェントがすべて完了したら、一時ファイルの内容をサマリーに統合する

## 並列起動のポイント

Claude Code では、1回のメッセージで複数の Agent ツールを呼び出すと並列実行されます。
プロンプトを 1 つずつ送るのではなく、**2つを同じメッセージにまとめて送る**のが効率的です。

Claude Code に対して次のように依頼します:

```
以下の2つのエージェントを同時に起動してください。

[統計家エージェントのプロンプトをここに貼る]

[専門医エージェントのプロンプトをここに貼る]
```

## 一時ファイルについて

- エージェントの出力は return result だけでなく必ず一時ファイルにも書き出させること
- context compaction が起きると return result は消えるが、一時ファイルは残る
- セッション再開後は `ls {一時ディレクトリ}/eval_*.md` で残存ファイルを確認する

`{一時ディレクトリ}` の実際の値:

| OS | パス |
|---|---|
| Windows | `C:\Users\{ユーザー名}\AppData\Local\Temp` (`echo %TEMP%` で確認) |
| Mac / Linux | `/tmp` |
